# HaySub հանրային դիտարկիչ

Հանրային կատալոգը՝ `/catalog`։ `HAYSUB_PUBLIC=1` ռեժիմում այն հասանելի է նաև `/` հասցեում։ Սեփականատիրոջ գործող գործիքները՝ `/admin`։ Տեղային ռեժիմի `/` աշխատանքային էջը պահպանված է։

Միայն հրապարակված և պատրաստ ֆիլմերն են հայտնվում կատալոգում՝ անկախ տեղային կամ ամպային աղբյուրից։ Հին գրառումների հրապարակման ամսաթիվը սկզբում լրացվում է ստեղծման ամսաթվով, քանի որ նախկին ճշգրիտ հրապարակման ամսաթիվ չի պահպանվել։ Նոր հրապարակումների ամսաթիվը պահպանվում է առանձին։

Պաստառը սեփականատերը կարող է ընտրել ֆիլմի կառավարման հատվածում՝ PNG, JPEG կամ WebP, առավելագույնը 2 ՄԲ։ Այն պահվում է գործող SQLite բազայում և պահանջում է նույն պահուստավորումը։ Պաստառ չունեցող կամ չբեռնվող նկարի փոխարեն ցուցադրվում է տեղային SVG պատկերը։

Տևողությունը վերցվում է գործող API-ից։ Եթե ամպային հղման տևողությունը դեռ հայտնի չէ, քարտում ցուցադրվում է `—:—`։ Ֆիլմը բացելուց և metadata-ն բեռնվելուց հետո տևողությունը պահվում է այդ դիտարկիչում՝ նաև ավարտված դիտումից հետո։

Առաջընթացի բանալին՝ `haysub:progress:v1:{video_id}`։ Այն պահվում է միայն տվյալ դիտարկիչում/կայքի հասցեում, առանց հաշվի կամ սարքերի միջև համաժամացման։ Արգելափակված պահոցի դեպքում նվագարկումը շարունակում է աշխատել։ Որոնումն ու կատալոգի ոլորումը պահվում են տվյալ ներդիրի sessionStorage-ում։

## Տեղային գործարկում

PowerShell-ում, նախագծի պանակից՝

```powershell
$env:HAYSUB_PUBLIC = '0'
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8001
```

1. Բացիր `http://127.0.0.1:8001/admin`։ Օգտագործիր երկու պատրաստ փորձնական ֆիլմ՝ ցանկալի է առնվազն 3 րոպե տևողությամբ։ Հրապարակիր երկուսը, մեկին ավելացրու պաստառ։
2. Բացիր `http://127.0.0.1:8001/catalog`։ Ստուգիր քառակուսի քարտերը, բացակայող պաստառի փոխարինումը, նոր հրապարակումների հերթականությունը և հայերեն որոնումը՝ նաև մեծատառերով ու «և/ԵՎ»-ով։
3. Սեղմիր քարտը։ Նույն ներդիրում պետք է բացվի `/watch/{id}`։ Պատճենիր հասցեն նոր ներդիրում և թարմացրու այն. էջը պետք է աշխատի։ Սկզբնական բացումը չպետք է պարտադրի autoplay։
4. Սեղմիր Play, ստուգիր հայերեն ենթագրերը, առաջ/հետ անցումը, 1.5× արագությունն ու լիաէկրանը։ Անցիր, օրինակ, 60-րդ վայրկյանին, նվագարկիր ևս 6 վայրկյան և դադարեցրու։
5. Վերադարձիր վերևի «Վերադառնալ ֆիլմերին» հղումով։ Ստուգիր 3px առաջընթացի գիծը, «Շարունակել դիտումը» բաժինը և պահպանված որոնումը/ոլորումը։ Կրկնիր նաև դիտարկիչի Back կոճակով՝ առանց էջի թարմացման։
6. Կրկին բացիր ֆիլմը. metadata-ից հետո դիրքը պետք է վերականգնվի, իսկ Play-ը մնա քո ընտրությանը։ Սեղմիր «Սկսել սկզբից»․ դիրքը պետք է դառնա 0, և պահպանված առաջընթացը մաքրվի։
7. Երկրորդ ֆիլմում պահիր այլ դիրք, ապա կրկին բացիր առաջինը։ Ֆիլմերը չպետք է կիսեն առաջընթացը։
8. Անցիր ֆիլմի վերջին 20 վայրկյանին, վերադարձիր կատալոգ․ առաջընթացի գիծը և շարունակելու գրառումը պետք է անհետանան։ Կրկնիր մինչև իրական `ended` իրադարձությունը։
9. Փորձնական ֆիլմը հանիր հրապարակումից `/admin`-ում։ Այն պետք է անհետանա կատալոգից, իսկ նախկին դիտման հասցեն ցուցադրի հասանելի չլինելու հաղորդագրություն։ Ջնջված գրառման նույն վարքն ավտոմատ թեստն է ստուգում մեկուսացված բազայում։
10. Արգելափակիր կայքի պահոցը դիտարկիչի կարգավորումներով, կրկին բացիր ֆիլմը և ստուգիր, որ այն նվագարկվում է։

## Ավտոմատ ստուգումներ

```powershell
.\.venv\Scripts\python.exe -m pytest -q
node --test tests/*.test.cjs
```

Python թեստերն աշխատում են մեկուսացված բազաներով և ստուգում են երթուղիները, հրապարակման սահմանները, պաստառները և սեփականատիրոջ մուտքը։ Node թեստերը օգտագործում են նմանակված DOM/media իրադարձություններ և ստուգում են պահպանումը, 5 վայրկյան պարբերականությունը, վերականգնումը, վերագործարկումը, ավարտը, երկու ֆիլմերի անկախությունը, որոնումը և վերադարձից հետո գծերի թարմացումը։ Դրանք իրական դիտարկիչով կամ իրական վիդեոյի ապակոդավորմամբ փորձարկումներ չեն։

## Իրական շարժական սարքերով ստուգում

Desktop Chrome-ի առանձին headless փորձարկմամբ հրապարակված իրական ամպային ֆիլմի համար ստուգվել են metadata-ի բեռնումը (1920×1080), մեծ 16:9 տարածքը, Play-ը, դիրքի պահպանումը, կատալոգի առաջընթացի գիծը, նույն ներդիրում վերադարձը, առանց autoplay-ի վերականգնումը, «Սկսել սկզբից»-ը և native հայերեն ենթագրերի բեռնումը։ Սա ավտոմատ desktop դիտարկիչի ստուգում է, ոչ ձեռքով կամ իրական հեռախոսով փորձարկում։

Իրական iPhone Safari և Android Chrome փորձարկումներ այս աշխատանքում չեն կատարվել։ Կայքի սարքից հասանելի HTTPS հասցեով առանձին կրկնիր վերևի 2–8 քայլերը՝ ստուգելով նաև ուղղահայաց/հորիզոնական դիրքերը, native ենթագրերի ընտրությունը, լիաէկրան մուտքն ու ելքը, հավելվածների միջև անցումն ու վերադարձը։ Տեղային `127.0.0.1` հասցեն հեռախոսից հասանելի չէ։
