# HaySub Chrome հավելում — ենթագրեր և հայերեն թարգմանություն

**Public release (1.3):** viewers can search the shared Armenian subtitle library
inside the popup. Publish chosen translations on the owner website first. The
development folder still targets your local server. To host it and create the
public Chrome Web Store ZIP, follow [../docs/PUBLISHING.md](../docs/PUBLISHING.md).
Public builds use one HTTPS catalog server and keep all translation/management
operations owner-only. Do not send viewers this localhost development folder.

**1.2 տարբերակ․ այլ կայքերի HTML5 տեսանյութեր։** Կայքում սկսիր տեսանյութը,
սեղմիր HaySub-ը և ընտրիր համապատասխան SRT/VTT ֆայլը։ Ներկառուցված player-ի
համար կան frame-ի ընտրություն և առանձին domain-ի թույլտվություն։ Կարդա
[այլ կայքերի հրահանգները](GENERIC_SITES.md)։ YouTube-ի հոսքը պահպանված է։
Սովորական տեղային ֆայլը սերվեր չի պահանջում. այլ կայքերում թարգմանությունը
լռելյայն անջատված է։ Kinogo-ի իրական նվագարկիչը Chrome-ում դեռ չի ստուգվել։

Երաժշտության առանձին նշումները (`[music]`, `[музыка]`, `[երաժշտություն]`, `♪`)
չեն ցուցադրվում, նաև արդեն պահված ֆայլերում։ Backend-ը դրանք բաց է թողնում՝
առանց Gemini թարգմանության։ Երգի բառերն ու երաժշտության մասին երկխոսությունը
պահպանվում են։ Նոր ֆիլտրի համար reload արա հավելումը և թարմացրու YouTube էջը։

Այս հավելումը առանձին է HaySub վեբ հավելվածից։ Այն ցուցադրում է քո ընտրած
SRT/VTT ֆայլի տեքստը հենց **youtube.com-ի տեսանյութի վրա**։ Այժմ նաև միանում է
գործող Python backend-ին՝ ֆայլը կամ YouTube ենթագրերը հայերեն թարգմանելու համար։
API բանալին մնում է միայն backend-ի `.env` ֆայլում։ Առանց թարգմանության տեղային
դիտման համար անջատիր «Թարգմանել հայերեն» ընտրանքը. այդ ռեժիմում սերվեր պետք չէ։

## Windows-ում բեռնում

1. Chrome-ում բացիր `chrome://extensions`։
2. Միացրու **Developer mode**։
3. Սեղմիր **Load unpacked**։
4. Ընտրիր այս թղթապանակը՝
   `C:\Users\Milena Mehrabyan\Desktop\Armenian-subtitles\extension`։
5. Բացիր կամ թարմացրու YouTube տեսանյութի էջը, Chrome-ի հավելումների ցանկից
   սեղմիր **HaySub**, ապա ընտրիր SRT կամ VTT ֆայլը։ Կարող ես ամրացնել հավելման
   պատկերակը Chrome-ի գործիքագոտում։

Սկզբում փորձիր `extension/sample.srt`-ը։ Սա մեր գրած փորձնական երկլեզու տեքստն է,
ոչ որևէ ֆիլմի իրական ենթագիր։ Այն տեսանելի է տեսանյութի առաջին 23 վայրկյանում։
4–5 վայրկյանների ընթացքում միաժամանակ ցուցադրվում են երկու հատվածները։

Կոդը փոխելուց հետո `chrome://extensions`-ում սեղմիր հավելման **Reload** կոճակը,
ապա թարմացրու YouTube-ի էջը։ Հին բաց էջում նոր content script-ը չի բեռնվում ինքնաբերաբար։

Հայերեն թարգմանության համար նախ գործարկիր Python սերվերը հիմնական նախագծից՝

```powershell
.\.venv\Scripts\python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

`.env`-ում պետք է լրացված լինեն `GEMINI_API_KEY` և `GEMINI_MODEL`։ Այս տարբերակն
Backend-ի պարտադիր host permission-ը `http://127.0.0.1/*` է. դրա ցանցային կոդը ֆիքսված
է `http://127.0.0.1:8000` հասցեին։ Reload-ից հետո թույլատրիր նոր loopback permission-ը,
եթե Chrome-ը հարցնի, և թարմացրու YouTube-ը։ Այլ կայքերի հասանելիություն չի ավելացվել։

## Թարգմանության հոսքը

«Թարգմանել հայերեն»-ը լռելյայն միացված է։ Popup-ը բացելիս, եթե ֆայլ կամ նախորդ
աշխատանք չկա, սկսվում է YouTube ենթագրերի ստացումն ու թարգմանությունը։ Սկզբում
նախընտրելի են հեղինակի, ապա՝ ավտոմատ ենթագրերը։ Ամեն աղբյուրում նախընտրելի է
անգլերենը, բայց կարող են օգտագործվել նաև այլ հասանելի բնօրինակ լեզուներ։
YouTube-ի ավտոմատ թարգմանված ուղիները չեն օգտագործվում։

Եթե վերբեռնում ես SRT/VTT, այն ունի առաջնահերթություն. նախկին ավտոմատ աշխատանքը
չեղարկվում է, և թարգմանվում է հենց քո ֆայլը։ Պատրաստ հայերեն հատվածները հայտնվում
են աստիճանաբար՝ նույն ժամանակներով։ Անպատրաստ պահերին բնագիրը չի ցուցադրվում
որպես հայերեն արդյունք։ Popup-ը փակելը չի դադարեցնում ընթացքը՝ քանի դեռ YouTube
էջը բաց է։ Ընթացքը տեսանելի է popup-ի progress bar-ում։ Կան «Կրկնել» և «Դադարեցնել»
կոճակներ։ Շեղումը կիրառվում է նաև թարգմանության առաջնահերթ հատվածը որոշելիս։

Եթե ենթագրեր չկան կամ YouTube-ը չի թույլատրում ստանալ դրանք, երևում է սխալ և
կարող ես վերբեռնել ֆայլ։ Whisper դեռ չկա։ Սերվերի/բանալու բացակայությունը հստակ
հաղորդվում է։ Gemini ծառայության սխալի դեպքում գործը կանգնում է սահմանափակ
կրկնափորձերից հետո, իսկ պատրաստ հատվածները մնում են քեշում։

## Կառավարում

- Միացրու կամ անջատիր ենթագրերը՝ առանց YouTube-ի native CC կոճակը փոխելու։
- Ընտրիր տառաչափը, տեքստի գույնը, սև ֆոնի անթափանցությունը և բարձրությունը։
- **Դրական շեղումը ուշացնում է** ենթագրերը. `+2` նշանակում է 2 վրկ ավելի ուշ։
  **Բացասական շեղումն առաջ է բերում**. `−2` նշանակում է 2 վրկ ավելի շուտ։
- Տեսքի կարգավորումները ընդհանուր են։ Ֆայլն ու շեղումը կապվում են տվյալ
  YouTube video ID-ին և վերականգնվում են հաջորդ այցելության ժամանակ։
- «Մաքրել այս ֆայլը» ջնջում է տվյալ տեսանյութի կապն ու շեղումը։
  «Մաքրել բոլոր ֆայլերը» ջնջում է բոլոր ենթագրերն ու շեղումները՝ պահելով տեսքի կարգավորումները։

Ֆայլը պետք է լինի UTF-8, ոչ դատարկ և մինչև 2 ՄԲ, առավելագույնը՝ 10 000 հատված։
Դատարկ/զրոյական հատվածները բաց են թողնվում։ Բացասական տևողությունն ու սխալ
ժամանակները տալիս են հայերեն սխալ։ SRT/VTT ձևավորման պիտակները հանվում են,
իսկ տեքստը ցուցադրվում է `textContent`-ով։ VTT-ի STYLE/REGION/NOTE բլոկները չեն
կատարվում։ Գույնն ու դիրքը կառավարվում են հավելման կարգավորումներով։

Պահված ֆայլերի համար օգտագործվում է `chrome.storage.local`։ Հավելումն ունի
8 ՄԲ պահպանման բյուջե՝ Chrome-ի քվոտայից ցածր պահուստ թողնելով։ Սահմանաչափի
կամ պահպանման սխալի դեպքում ցուցադրվում է հայերեն հաղորդագրություն, և հին
ֆայլը չի փոխարինվում։ Chrome-ի պրոֆիլների միջև ֆայլերը չեն համաժամեցվում։

## Կառուցվածքը՝ սովորելու համար

- `manifest.json` — Manifest V3, popup և YouTube-ին սահմանափակված content script։
  Պարտադիր API permissions-ը՝ `storage`, `activeTab`, `scripting`։ Այլ կայքում
  հասանելիությունը տրվում է HaySub-ը սեղմելիս։ `webNavigation`-ը և frame-ի domain-ը
  խնդրվում են միայն ներկառուցված player-ի ընտրության համար։ `cookies`, `tabs`,
  `unlimitedStorage` կամ մշտական հասանելիություն բոլոր կայքերին չի պահանջվում։
  Backend-ի պարտադիր host permission-ը մնում է միայն loopback հասցեն։
- `core.js` — մաքուր JavaScript ֆունկցիաներ՝ parser, ժամանակային որոնում,
  կարգավորումների սահմաններ և տեսապատկերի երկրաչափություն։
  Վեբ հավելվածի `static/player.js`-ի պես կիրառվում է `[start, end)` միջակայքը։
  Python parser-ի ժամանակային/չափային ստուգումների գաղափարները կիրառված են
  տեղային JavaScript տարբերակում, որպեսզի բնագրի ցուցադրումը աշխատի նաև առանց Python-ի։
- `content.js` — գտնում է YouTube-ի `HTMLVideoElement`-ը և ստեղծում մեկ overlay։
  Յուրաքանչյուր render-ի ժամանակ կարդում է `video.currentTime`-ը։
  `requestAnimationFrame`-ը միայն թարմացման ազդանշան է, ոչ առանձին ժամացույց։
  Pause, buffering, seek և արագության փոփոխությունները չեն առաջացնում ժամանակի շեղում։
- `popup.html`, `popup.css`, `popup.js` — ֆայլի ընտրություն, UTF-8 ստուգում,
  կարգավորումներ, պահպանում և մաքրում։ Popup-ը video ID-ն ստանում է էջի content
  script-ից, ոչ թե բոլոր բաց էջերի URL-ների հասանելիության permission-ից։
- `tests/` — Node-ի ներկառուցված թեստեր՝ առանց լրացուցիչ npm փաթեթների։
- `background.js` — privileged fetch bridge՝ միայն ֆիքսված local backend հասցեին։
  Չի ընդունում կամայական URL, cookie կամ API բանալի։
- `translation-client.js` — բաց YouTube էջից շարունակվող polling և playback-ի
  դիրքի փոխանցում։ Service worker-ի մշտական timer-ի վրա չի հիմնվում։

Overlay-ը միացված է YouTube player-ի ներսում, անտեսում է մկնիկի գործողությունները,
հաշվի է առնում letterboxing-ը և ներքևում տեղ է թողնում կառավարման կոճակներին։
Resize/fullscreen փոփոխությունները նորից հաշվարկում են չափերը։ YouTube-ի
գովազդի վիճակում overlay-ը թաքցվում է։ Նոր տեսանյութի անցման ժամանակ հին
overlay-ը և video listener-ները հեռացվում են։ Կրկնակի մեկնարկը նախ մաքրում է
հին content-script օրինակը։

## Ավտոմատ ստուգումներ

Ծրագրի հիմնական թղթապանակից՝

```powershell
node --test extension/tests/core.test.cjs extension/tests/content.test.cjs extension/tests/popup.test.cjs extension/tests/backend.test.cjs extension/tests/translation-client.test.cjs
node --check extension/core.js
node --check extension/content.js
node --check extension/popup.js
node --check extension/background.js
node --check extension/translation-client.js
```

Կատարվել և անցել են **26 extension թեստերը**։ Ստուգվել են SRT/VTT, բազմատող UTF-8,
դատարկ հատվածներ, HTML-ի անվտանգ մշակում, համընկնող հատվածների պահպանում,
offset-ի նշանը, սահմանային ժամանակներ, video clock-ի օգտագործում,
SPA մաքրում, կրկնակի overlay/listener-ների կանխում, geometry, storage quota,
ֆայլերի մաքրում և սխալ ֆայլի հաղորդագրություններ։
Նոր ստուգումները ներառում են backend bridge-ը, հայերեն հատվածների պահպանումը,
բնագրի սխալ ներկայացման կանխումը, քվոտայի դեպքում չեղարկումը, ֆայլի
առաջնահերթությունը և popup-ից անկախ polling-ը։ Python suite-ում անցել է
85 թեստ՝ ներառյալ բնօրինակ լեզվով captions-ի և cancellation-ի նոր ստուգումները։
Այս աշխատանքի ընթացքում նոր իրական Gemini հարցում չի կատարվել։

Content/popup թեստերը օգտագործում են DOM-ի և Chrome API-ի փոքր փոխարինիչներ։
Դրանք **իրական Chrome կամ YouTube տեսողական ստուգում չեն**։ Այս միջավայրում
կապակցված Chrome automation հասանելի չէ. իրական տեղադրումը չի փորձարկվել։

## Chrome-ում ձեռքով ստուգելու ցանկ

1. Անջատիր «Թարգմանել հայերեն»-ը և անջատված Python սերվերով վերբեռնիր `sample.srt`։
2. 1–5 վրկ ընթացքում ստուգիր հայերենն ու անգլերենը, 4–5 վրկ՝ երկու cue-ի համընկնումը։
3. Pause/resume, առաջ/հետ seek և 0.5×/2× արագություն. տեքստը պետք է համապատասխանի
   **նվագարկիչի ժամանակին**։ Buffering-ի դեպքում այն չպետք է առաջ շարժվի։
4. Փորձիր normal, theater և YouTube-ի desktop fullscreen ռեժիմները, ապա resize։
   Տեքստը պետք է մնա տեսապատկերի սահմաններում, իսկ YouTube controls/CC-ը՝ աշխատող։
5. Փոխիր տառաչափը, գույնը, opacity-ն, դիրքը, enable-ը և `+2`/`−2` շեղումները։
6. Սեղմիր YouTube-ի այլ տեսանյութի հղում՝ առանց լրիվ refresh-ի. հին տեքստը պետք է
   անհետանա։ Հետ վերադարձիր՝ ստուգելու միայն այդ տեսանյութի ֆայլի վերականգնումը։
7. Թարմացրու էջը/փակիր ու բացիր Chrome-ը՝ պահված ֆայլն ու կարգավորումները ստուգելու համար։
8. Փորձիր սխալ UTF-8, ոչ SRT/VTT, դատարկ ֆայլ և մաքրման երկու կոճակները։
   Բոլոր պահված ֆայլերը մաքրելուց հետո այլ YouTube էջերում էլ overlay-ը պետք է թաքնվի։
9. Գործարկիր backend-ը, միացրու թարգմանությունը և վերբեռնիր անգլերեն/ռուսերեն ֆայլ։
   Ստուգիր հայերեն հատվածները, փակիր popup-ը և համոզվիր, որ առաջընթացը շարունակվում է։
10. Առանց ֆայլի փորձիր հասանելի YouTube captions-ով տեսանյութ, ապա՝ captions չունեցողը։
    Փորձիր «Դադարեցնել», «Կրկնել» և automatic գործի ընթացքում նոր ֆայլ վերբեռնելը։

## Սահմանափակումներ և գաղտնիություն

Թարգմանությունը կատարվում է FastAPI backend-ի միջոցով։ Միացված թարգմանությամբ
ֆայլի տեքստը/տեսանյութի ID-ն ուղարկվում է local backend-ին, իսկ երկխոսությունը՝ Gemini-ին։
Gemini-ի գործող հաշվի պայմաններն ու սահմանաչափերը կիրառվում են. billing չի միացվում։
Հայերեն ֆայլ պատրաստելու համար կարող ես առանձին բացել HaySub վեբ հավելվածի
ներքևի «Ենթագրերի թարգմանիչ» բաժինը, թարգմանել SRT/VTT-ն ու ներբեռնել `_hy.srt`
արդյունքը։ Այն հետո ընտրիր այս հավելման մեջ։ Այդ վեբ բաժինը պահանջում է գործող
Python սերվեր և backend-ի Gemini կարգավորում։ Առանց թարգմանության տեղային ռեժիմը
շարունակում է աշխատել ինքնուրույն։ API բանալիները երբեք չեն պահվում հավելման մեջ։

Եթե backend-ը վերագործարկվել է, սեղմիր «Կրկնել»՝ պահված source/cache-ից շարունակելու
համար։ YouTube էջը փակելիս backend-ը կարող է շարունակել մշակումը. այն դադարեցնելու
համար նախ սեղմիր «Դադարեցնել»։ Տեսանյութի փոփոխությունը միայն թաքցնում է հին overlay-ը։

Հիմնական թիրախը Windows-ի desktop Chrome-ն է։ Օգտագործիր YouTube-ի fullscreen
կոճակը. բջջային/native video fullscreen-ը կամ Picture-in-Picture-ը սովորական DOM
overlay չեն ցուցադրում։ Չափազանց շատ միաժամանակյա տեքստը փոքր տեսապատկերում կարող է
դառնալ փոքր/սահմանափակված. հավելումը փոքրացնում է այն՝ տեսանյութից դուրս չգալու համար։
YouTube-ի DOM-ի հետագա փոփոխությունները կարող են պահանջել selector-ների թարմացում։

Հավելումը չի փոխում video playback-ը, չի ներբեռնում/պրոքսիացնում տեսանյութ,
չի ստանում cookies և չի շրջանցում մուտքի կամ նվագարկման սահմանափակումներ։

[Storage API](https://developer.chrome.com/docs/extensions/reference/api/storage),
[Tabs messaging](https://developer.chrome.com/docs/extensions/reference/api/tabs)։
